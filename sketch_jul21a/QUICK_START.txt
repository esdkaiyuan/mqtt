🚀 第一步：一键启动服务

   Windows:  双击 START.bat

   手动启动:
   1. 打开终端，进入项目目录
   2. 启动后端: cd backend && python -m uvicorn app.main_sqlite:app --host 0.0.0.0 --port 8000 --reload
   3. 启动前端: cd frontend && python -m http.server 3000


📍 第二步：访问系统

   前端界面: http://localhost:3000
   后端API:  http://localhost:8000
   API文档:  http://localhost:8000/docs


🔌 第三步：烧录ESP32固件

   1. 打开Arduino IDE
   2. 打开文件: arduino_firmware/ESP32_Raw_Data/ESP32_Raw_Data.ino
   3. 修改配置:
      #define WS_SERVER_HOST  "你的电脑IP地址"  // ← 修改这里
      
      获取电脑IP:
      - Windows: 按Win+R，输入cmd，输入ipconfig，找IPv4地址
      - Mac/Linux: 输入ifconfig，找inet地址
      
   4. 选择开发板: 工具 → 开发板 → ESP32S3 Dev Module
   5. 选择端口: 工具 → 端口 → 选择ESP32端口
   6. 点击"上传"按钮烧录固件


🔌 第四步：连接硬件

   ESP32-S3              MPU6500
   ──────────────────────────────────
   GPIO21 (SDA)    ───►  SDA
   GPIO22 (SCL)    ───►  SCL
   3.3V            ───►  VCC
   GND             ───►  GND
   GPIO2           ───►  LED


📊 第五步：验证数据

   1. ESP32连接后，LED会显示连接状态
   2. 打开前端界面: http://localhost:3000
   3. 查看"最新数据"表格
   4. 查看统计数据

   数据验证（静止时）:
   - az ≈ 9.81（重力加速度）
   - ax ≈ 0
   - ay ≈ 0
   - gx, gy, gz ≈ 0


💡 常用命令

   查看统计信息:
   curl http://localhost:8000/api/stats

   查看数据列表:
   curl "http://localhost:8000/api/data?limit=10"

   导出CSV数据:
   curl "http://localhost:8000/api/export?device_id=ESP32_001" -o data.csv

   查看所有API:
   打开浏览器访问 http://localhost:8000/docs


🔧 常见问题

   Q: 前端是白屏幕？
   A: 检查前端服务是否启动（http://localhost:3000）

   Q: ESP32无法连接？
   A: 检查：
      - IP地址是否正确
      - 防火墙是否允许8000端口
      - ESP32和电脑在同一网络

   Q: MPU6500初始化失败？
   A: 检查I2C接线，确认供电为3.3V

   Q: 数据全是0？
   A: 检查MPU6500接线是否正确
