
## 核心算法

### 1. 摔倒检测算法

**算法类型**: 基于阈值的滑动窗口检测

**检测流程**:
1. 维护500ms的滑动窗口（50个样本@100Hz）
2. 计算每个窗口的特征值：
   - 加速度幅值：`sqrt(ax² + ay² + az²)`
   - 角速度幅值：`sqrt(gx² + gy² + gz²)`
3. 检测摔倒条件：
   - 加速度突增 > 2.5g
   - 角速度突增 > 300°/s
   - 随后加速度快速减小（撞击后静止）
4. 满足条件则标记为摔倒事件

**参数配置**:
```env
FALL_WINDOW_SIZE=50          # 窗口大小（样本数）
FALL_ACCEL_THRESHOLD=2.5     # 加速度阈值（g）
FALL_GYRO_THRESHOLD=300.0    # 角速度阈值（°/s）
FALL_SAMPLE_RATE=100         # 采样率（Hz）
```

### 2. 数据校准算法

**自动校准**（ESP32启动时执行）:
1. 保持设备静止2秒
2. 采集100个样本
3. 计算加速度和陀螺仪的偏移量
4. 后续数据自动补偿偏移

**校准公式**:
```
校准后值 = 原始值 - 偏移量
```
