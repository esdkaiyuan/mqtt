# T-46 看板大屏与跨用户分享 实施计划

> 版本：v1.0　创建日期：2026-10-22　状态：已交付
> 目标：补齐 G-10-1，让看板具备公开只读大屏、多看板定时轮播与跨用户分享链接。

---

## 1. 背景与范围

T-21 的看板只能由创建者登录后查看。本任务新增：

- **可撤销的分享令牌**：一个分享可包含多个看板，按固定间隔轮播；
- **公开只读大屏页** `/display/{token}`：无需登录、自动刷新、全屏、深浅一致的深色图表；
- **跨用户分享**：任何拿到链接的人都能只读访问，不需要平台账号；
- 创建者可启停、编辑、轮换令牌或删除分享。

不在本任务范围：按成员 / 角色授权（G-8-1）、看板编辑权限共享、分享访问审计、口令保护、到期时间、水印。

---

## 2. 分享模型

`dashboard_share`（V25，只加表）：

| 列 | 说明 |
|---|---|
| `user_id` | 创建者 |
| `name` | 大屏标题 |
| `token_hash` | 令牌 SHA-256（唯一，**不存明文**） |
| `token_preview` | 令牌前 8 位，仅列表识别 |
| `dashboard_ids` | 有序看板 ID JSON 数组 |
| `interval_seconds` | 轮播间隔（默认 15，5..3600） |
| `enabled` | 启停；停用后公开链接立即失效 |

- 令牌为 256 位随机数（Base64 URL，无填充），明文只在创建 / 轮换响应返回一次；
- 轮换后旧令牌立即失效；
- 公开读取时重新校验看板归属与设备归属，删除 / 转移的看板自动跳过；全部不可用返回 `6305`。

## 3. 后端接口

### 3.1 创建者接口（登录）

`/dashboards/shares`

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 本人分享列表（不含明文令牌） |
| POST | `/` | 创建分享，返回明文令牌与 `/display/{token}` |
| PUT | `/{id}` | 更新名称 / 看板集合 / 间隔 / 启停 |
| DELETE | `/{id}` | 删除分享 |
| POST | `/{id}/rotate` | 轮换令牌，返回新令牌 |

校验：分享名称 ≤64；看板 1..`max-share-dashboards` 且均为本人所有；间隔在配置区间内；
分享数上限 `max-shares`（`6307`），非法配置 `6306`，不存在 / 越权 `6305`。

### 3.2 公开接口（无需登录）

`GET /public/dashboard-shares/{token}`：

- 返回分享标题、轮播间隔、按顺序的看板 `{id, name, config, updatedAt}`；
- 返回 `deviceNames`（仅分享创建者名下设备），供图表图例；
- 看板配置中的非本人设备 ID 会被过滤；
- 令牌无效 / 停用 / 看板全部不可用统一 `6305`，不区分原因；
- `SecurityConfig` 显式 `permitAll`，并有过滤器链测试守护。

### 3.3 配置

`app.dashboard` 新增：

- `max-shares`（默认 20）
- `max-share-dashboards`（默认 10）
- `share-interval-min-seconds`（默认 5）
- `share-interval-max-seconds`（默认 3600）

均已贯通 `application.yml` / `.env.example` / `docker-compose.yml`。

## 4. 前端

- `api/dashboardShare.js`、`composables/useDashboardShares.js`：分享 CRUD 与令牌轮换；
- `components/dashboard/DashboardShareDialog.vue`：
  - 已有分享列表（启停 / 编辑 / 轮换 / 删除）；
  - 新建 / 编辑表单（名称、看板多选、轮播间隔、启停）；
  - 创建 / 轮换后展示**仅一次**的完整链接，支持复制；
- `views/workbench/board/BoardList.vue`：页头「大屏分享」与卡片「分享」入口，按看板预选；
- `views/display/DisplayBoard.vue`（公开路由 `/display/:token`）：
  - 深色全屏布局、实时时钟、全屏按钮、轮播圆点、播放 / 暂停；
  - 多看板按 `intervalSeconds` 自动轮播；单看板不轮播；
  - 面板数据每 60 秒自动刷新；
  - 令牌失效展示「链接无效或已失效」；
- `BoardPanel` / `PropertyTrendChart` / `ChartCard` 新增 `dark` 与 `refreshInterval`，仅大屏使用深色配色，不影响工作台。

## 7. 关键决策与已知限制

1. **令牌只存哈希**：数据库泄露不能直接获得访问权；代价是列表无法再次显示完整链接，只能轮换。
2. **公开链接即凭据**：任何拿到链接的人都能只读访问；不提供口令、到期时间、访问审计或水印，后续如需可按分享增加。
3. **看图板不看成员**：分享是「看板集合 + 轮播配置」，不引入成员 / 角色模型，避免与 G-8-1 的权限体系混淆。
4. **公开视图二次过滤**：创建后看板可能被删除或设备转移，公开读取每次重新校验归属，只返回仍属于创建者的看板与设备。
5. **配置变更需刷新页面**：大屏只在首次加载读取分享配置；看板名称 / 面板变更需重新打开链接（数据本身每 60 秒刷新）。
