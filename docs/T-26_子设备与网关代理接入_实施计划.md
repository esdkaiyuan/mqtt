## 计划概览

- **Goal**：落地子设备与网关代连接入，`device` 表补父子拓扑，网关账号可代表其子设备收发报文，既有摄取、命令、影子、告警、规则、场景、属性历史与 OTA 链路零特判。
- **Architecture**：采用扁平主题，子设备主题与直连设备同形（`device/{deviceKey}/{messageType}`），平台侧新增面收敛为「拓扑数据 + 委托授权」两块；授权判定在 `AclEvaluator.allowDevice` 前缀不匹配时转入 `allowDelegated`，以拓扑缓存判定归属。
- **Tech Stack**：Java 17 + Spring Boot 4.1.1 + MyBatis-Plus 3.5.17 + Flyway + JUnit 5 + Mockito + ArchUnit；Vue 3 控制台与文档站。
- **Spec**：`docs/T-26_子设备与网关代理接入_设计文档.md` v1.0。
- **Global Constraints**：
  - 不改 `MqttMessageHandler`（含 `subscribe`）、`IngestPipeline` / `IngestDispatcher` / `IngestPersistenceService`、`EmqxAuthServiceImpl`、`DeviceCommandServiceImpl`、`DeviceCredentialAuthFilter`、`emqx-init.sh`。
  - 错误码自 6254 起，追加时把 `ResultCode` 第 116 行末项 `DEVICE_TOKEN_ISSUE_FAILED(6253, …)` 的分号改为逗号。
  - 迁移文件为 `V14__device_topology.sql`，`V1`~`V13` 零改动。
  - `AuthMeta` 新增字段为内存载体，不映射库列；拓扑变更须失效子设备与网关两侧缓存。
  - 子设备与网关必须同产品，跨产品一律拒 `6258`；网关角色只上抬不回落。
  - ArchUnit 既有规则不得放松，拓扑服务接口不得直接依赖 Mapper。
  - 默认模板 `device/{deviceKey}` 下子设备主题与直连设备逐条同形，共享订阅与分片无需改动。
  - `app.device-topology.enabled=false` 时全部新行为退化为空操作。
