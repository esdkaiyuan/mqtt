## P2 命令表补发支持（Mapper 扩展）

- [ ] `mapper/DeviceCommandRecordMapper.java` 新增
  - `int markQueued(@Param("commandId") String, @Param("nextAttemptAt") LocalDateTime, @Param("errorMessage") String)`：`SET status='QUEUED', next_attempt_at=?, error_message=? WHERE command_id=? AND status='PENDING'`
  - `int markRetry(@Param("commandId") String, @Param("nextAttemptAt") LocalDateTime, @Param("errorMessage") String)`：`SET attempt_count = attempt_count + 1, next_attempt_at=?, error_message=? WHERE command_id=? AND status='QUEUED'`
  - `int markSentFromQueued(@Param("commandId") String, @Param("sentAt") LocalDateTime)`：`SET status='SENT', sent_at=?, next_attempt_at=NULL WHERE command_id=? AND status='QUEUED'`
  - `int markFailedFromQueued(@Param("commandId") String, @Param("errorMessage") String, @Param("finishedAt") LocalDateTime)`：`SET status='FAILED', finished_at=?, next_attempt_at=NULL WHERE command_id=? AND status='QUEUED'`
  - `List<DeviceCommandRecord> selectQueuedByDevice(@Param("deviceId") Long, @Param("limit") int, @Param("now") LocalDateTime)`
  - `int countQueuedByDevice(@Param("deviceId") Long)`
  - `List<DeviceCommandRecord> selectDueQueued(@Param("now") LocalDateTime, @Param("limit") int)`：JOIN `device`（`status='ONLINE' AND enabled=1 AND deleted=0`）与 `product`（`status='ENABLED'）
- [ ] `resources/com/mqtt/cloud/mapper/DeviceCommandRecordMapper.xml` 同步新增 SQL
  - 所有状态迁移均为**条件更新**，返回受影响行数；`QUEUED` 守卫与既有 `status IN ('PENDING','SENT')` 守卫互不干扰

## P3 影子服务

- [ ] `config/ShadowProperties.java`（`@ConfigurationProperties(prefix = "app.shadow")`，字段见设计文档 §12）
- [ ] `service/DeviceShadowService.java`（接口，**不得依赖 mapper**）
  - `DeviceShadowResponse get(Long deviceId, Long productId)`
  - `void applyReported(Long deviceId, Collection<String> identifiers)`（回读权威库后合并，见设计文档 §9.4）
  - `void applyDesired(Long deviceId, JsonNode params)`（写入期望值并重算 delta）
  - 内部 record：`DeviceShadowResponse(boolean modeled, long version, Map<String,String> desired, Map<String,String> reported, Map<String,String> delta, LocalDateTime updatedAt)`
- [ ] `service/impl/DeviceShadowServiceImpl.java`
  - 读-改-写 + CAS：`insertIfAbsent` → 读 → 内存合并 / 重算 delta → `casUpdate`；受影响 0 行重试至多 `app.shadow.cas-retry` 次，仍失败仅记 WARN 放弃
  - `delta = { k: desired[k] | k ∈ desired 且 (k ∉ reported 或 desired[k] ≠ reported[k]) }`
  - reported 合并：按键回读 `device_property_latest` 权威最新值（复用其时间戳守卫），不写调用方传入值
  - JSON 序列化 / 反序列化 `Map<String,String>` 统一使用注入的 `ObjectMapper`
- [ ] `mapper/DevicePropertyLatestMapper.java` + `.xml` 增加 `List<DevicePropertyLatest> selectByIdentifiers(@Param("deviceId") Long, @Param("identifiers") Collection<String>)`

## P4 命令服务接入影子（离线入队）

- [ ] `service/impl/DeviceCommandServiceImpl.java`
  - 注入 `DeviceShadowService`（**单向依赖，无环**）
  - `property_set`：校验通过落库 `PENDING` 后，先 `deviceShadowService.applyDesired(deviceId, params)`，再判定投递
  - 投递判定：`device.status == 'ONLINE' && enabled == 1 && 产品 ENABLED` → 发布；否则 `property_set` 置 `QUEUED`（`next_attempt_at = now`），`service` 保持 T-15 行为
  - 发布异常：`property_set` → 置 `QUEUED` + 退避且不抛错；`service` → 仍抛 `4001`
  - 新增常量 `STATUS_QUEUED = "QUEUED"`
- [ ] `service/DeviceCommandService.java` 接口新增
  - `int flushQueued(Long deviceId, int limit)`：按 `next_attempt_at` 升序补发该设备的 `QUEUED`，成功 `QUEUED → SENT`，失败 `markRetry` 退避
  - `int sweepQueuedRetries()`：跨设备选取到期且设备在线 / 启用的 `QUEUED` 补发，次数耗尽置 `FAILED`
  - 复用既有 `publish` / `buildPayload`（不复制载荷构造逻辑）
