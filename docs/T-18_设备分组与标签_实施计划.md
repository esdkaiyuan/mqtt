## P1 迁移与数据模型

- [ ] `backend/src/main/resources/db/migration/V8__device_group_and_tag.sql`
  - 新建 `device_group`（自引用树 + `sort_order` + 逻辑删除 + 自引用外键 `ON DELETE SET NULL`）
  - 新建 `device_tag`（扁平 + `color` + 逻辑删除）
  - 新建 `device_group_relation`（`UNIQUE(device_id, group_id)`，物理行，无 `deleted`）
  - 新建 `device_tag_relation`（`UNIQUE(device_id, tag_id)`，物理行，无 `deleted`）
  - **只加表**，不改既有表，应用版本可安全回滚
  - 头部注释说明「只加表」「关联表为物理行」「自引用外键在逻辑删除下不触发」
- [ ] `entity/DeviceGroup.java`（`@TableName("device_group")`，`@Data @EqualsAndHashCode(callSuper=false)`；`createdAt` 用 `fill = FieldFill.INSERT`、`updatedAt` 用 `INSERT_UPDATE`；`deleted` 走全局逻辑删除；瞬态 `children` / `deviceCount` 用 `@TableField(exist = false)`）
- [ ] `entity/DeviceTag.java`（`@TableName("device_tag")`，字段对齐迁移）
- [ ] `entity/DeviceGroupRelation.java` / `entity/DeviceTagRelation.java`（**无逻辑删除**）
