# T-21 属性时序与可视化（Property Time-Series & Visualization） — 实施计划

> 版本：v1.0　创建日期：2026-10-03　最后更新：2026-10-03
> 上游依据：[`T-21_属性时序与可视化_设计文档.md`](./T-21_属性时序与可视化_设计文档.md)
> 交付原则：端到端可用（迁移 + 实体 + Mapper + 服务 + 接口 + 前端趋势图 / 看板 + 测试 + 文档），不做只有后端没有入口的半成品。
> 主题策略：**新建两张表**（`device_property_history` / `dashboard`，Flyway `V10`，只加表）；属性历史以 `ThingModelInterpretServiceImpl.interpretProperties` 内**第 4 条 try/catch 旁路**追加写；聚合走 `(device_id, identifier, reported_at)` 复合索引；**不改既有写入语义、不新增 MQTT 主题 / 不改 ACL、不改 `V1`~`V9`**；回滚只需摘除端点 / 页面 / 旁路，可选删表。

## P2 Mapper 与聚合 SQL

- [ ] `mapper/DevicePropertyHistoryMapper.java`（`@Mapper`，**不继承 `BaseMapper`**，仅三个自定义方法；设计文档 §7.1）
  - `int insertBatch(@Param("rows") List<DevicePropertyHistory> rows)`
  - `List<PropertyHistoryAggregate> aggregateByBucket(@Param("deviceIds") List<Long> deviceIds, @Param("identifiers") List<String> identifiers, @Param("startTime") LocalDateTime startTime, @Param("endTime") LocalDateTime endTime, @Param("bucketSeconds") long bucketSeconds, @Param("numeric") boolean numeric)`
  - `int purgeBefore(@Param("threshold") LocalDateTime threshold, @Param("batchSize") int batchSize)`
- [ ] `resources/com/mqtt/cloud/mapper/DevicePropertyHistoryMapper.xml`
  - `insertBatch`：`INSERT INTO device_property_history (device_id, identifier, data_type, value_text, reported_at) VALUES <foreach ...>(...)</foreach>`（空列表短路，由服务层保证非空）
  - `aggregateByBucket`（**统一放 XML**，与既有 `MessageMapper` / `DeviceLogMapper` 一致）：
    - 分桶列 `FROM_UNIXTIME(FLOOR(UNIX_TIMESTAMP(h.reported_at) / #{bucketSeconds}) * #{bucketSeconds}) AS time`
    - `<choose><when test="numeric">MIN/MAX/AVG(CAST(h.value_text AS DECIMAL(30,10))) AS minValue/maxValue/avgValue</when><otherwise>NULL AS minValue, NULL AS maxValue, NULL AS avgValue</otherwise></choose>`
    - `COUNT(*) AS sampleCount`；`WHERE h.reported_at &gt;= #{startTime} AND h.reported_at &lt; #{endTime}`（**半开区间**）+ `device_id IN <foreach>` + `identifier IN <foreach>`
    - `GROUP BY h.device_id, h.identifier, time` + `ORDER BY h.device_id ASC, h.identifier ASC, time ASC`
    - `resultType="com.mqtt.cloud.dto.response.PropertyHistoryAggregate"`；**全 `#{}` 占位符，无 `${}`**；**不分页故无 `countQuery`**
  - `purgeBefore`：`DELETE FROM device_property_history WHERE reported_at &lt; #{threshold} LIMIT #{batchSize}`
  - 头部注释说明：只追加、半开区间、`(device_id, identifier, reported_at)` 复合索引命中、`numeric` 分流避免对文本 `CAST`
- [ ] `mapper/DashboardMapper.java`（`@Mapper`，继承 `BaseMapper<Dashboard>`，纯单表 CRUD，无自定义 SQL / 无 XML）

## P3 服务层、配置与摄取旁路

- [ ] `service/PropertyHistoryService.java`（接口，**不得依赖 `..mapper..`**，ArchUnit 门禁）
  - `void append(Long deviceId, List<Sample> samples)`；嵌套 `record Sample(String identifier, String dataType, String valueText, LocalDateTime reportedAt)`
  - `List<PropertySeriesVO> query(Long userId, PropertyHistoryQueryDTO query)`
- [ ] `service/PropertyHistoryRetentionService.java`（接口）+ `service/impl/PropertyHistoryRetentionServiceImpl.java`
  - `int purgeExpired()`：阈值 = `now - retention-days`；分批循环 `purgeBefore` 直到影响行数 `< batchSize` 或达单轮上限
- [ ] `service/impl/PropertyHistoryServiceImpl.java`（流程见设计文档 §4.4 / §7.3）
  - 构造注入 `DeviceMapper` / `DevicePropertyHistoryMapper` / `ThingModelService` / `PropertyHistoryProperties`
  - **写入 `append`**：`enabled=false` → 直接返回；`samples` 空 → 直接返回；组装行（`deviceId` / `identifier` / `dataType` / `valueText` / `reportedAt`）→ `insertBatch`（异常由调用方旁路 `try/catch` 兜底）
  - **查询 `query`**：
    1. 设备归属校验：逐 `deviceId` `deviceMapper.selectById` → 空 = `2002`；`owner_id != userId` = `2003`
    2. 标识符校验：按设备 `productId` 经 `ThingModelService.getForProduct(productId)` 取定义；未建模 → `6226`；记录每个标识符 `type` 与 `numeric`（`NUMERIC_TYPES.contains(type)`）
    3. 参数归一化：解析 `startTime` / `endTime`（非法 / `start >= end` → `6225`）；跨度 > `maxRangeDays` → `6225`；`bucket` 白名单（非法 → `6227`）；序列数 > `maxSeries` → `6225`；桶数 > `maxPoints` → `6227`
    4. **按 `numeric` 分组调用 `aggregateByBucket`**（数值 / 非数值各一次；全同类型只调一次）
    5. 组装序列：`PropertyHistoryAggregate` 按 `(deviceId, identifier)` 分组、`time ASC` 排序，逐行映射为 `PropertyHistoryPoint`（`sampleCount→count` / `minValue→min` / `maxValue→max` / `avgValue→avg`）填入 `points`；未出现的组合补 `points: []`
    6. 返回 `List<PropertySeriesVO>`（`deviceId ASC, identifier ASC`）
- [ ] `service/DashboardService.java`（接口，**不得依赖 `..mapper..`**）+ `service/impl/DashboardServiceImpl.java`
  - `List<DashboardSummaryVO> list(Long userId)` / `DashboardDetailVO create(Long userId, DashboardSaveDTO dto)` / `DashboardDetailVO detail(Long userId, Long id)` / `DashboardDetailVO update(Long userId, Long id, DashboardSaveDTO dto)` / `void remove(Long userId, Long id)`
  - 归属：`userId` 由服务端注入；`detail` / `update` / `remove` 命中非本人（或不存在）一律 `6228`
  - 校验：`name` 非空且 ≤ 64 → 否则 `6229`；`config` 解析为 `DashboardConfig`（解析失败 / 字段超界 → `6229`）；`panels.size() <= maxPanels` → 否则 `6229`；每面板 `deviceIds` 非空 / `identifier` 非空 / `bucket` / `chartType` / `aggregation` 白名单 / `rangeDays <= maxRangeDays`；`list(userId).size() >= maxCount` 时 `create` → `6230`
- [ ] `config/PropertyHistoryProperties.java`（`@Data @Component @ConfigurationProperties(prefix = "app.property-history")`）
  - 字段 `enabled=true` / `maxRangeDays=31` / `maxSeries=20` / `maxPoints=500` / `retentionDays=30` / `cleanupEnabled=true` / `cleanupIntervalMs=3600000` / `cleanupBatchSize=1000`（带中文注释）
- [ ] `config/DashboardProperties.java`（`@Data @Component @ConfigurationProperties(prefix = "app.dashboard")`）

- [ ] `config/PropertyHistorySweeper.java`（`SchedulingConfigurer`，形状照 `RuleSweeper`）

  - 单次巡检 `try/catch`：异常只记 WARN / ERROR，**不冒泡、不中断调度线程**
- [ ] `service/impl/ThingModelInterpretServiceImpl.java` 新增**第 4 条旁路**（设计文档 §4.4）
  - 循环内 `historySamples.add(new PropertyHistoryService.Sample(identifier, spec.type(), valueText, record.receivedAt()))`（**复用同一份归一化样本，不重复解析**）

  - 新增构造依赖 `PropertyHistoryService`（若无循环依赖；若有则改用 `ObjectProvider` / setter，实施时确认）
