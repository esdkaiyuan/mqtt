## 5. 维护约定

- 新增能力必须同步：实施计划 → `ARCHITECTURE.md` → `DEPLOYMENT.md` → 站内文档站 → 本索引；
- 文档中的数量（控制器 / 端点 / 表 / 迁移 / 错误码）以代码为准，变更时同步核对；
- 相对链接指向本目录内文件；站内页面路径以 `/docs` 为前缀。
