## 1. 项目总览

### 1.1 项目背景
构建一个完整的MQTT云平台系统，支持MQTT核心通信、用户认证、设备管理、实时消息监控及历史数据查询。

### 1.2 技术栈
| 层级 | 技术选型 |
|------|----------|
| 前端 | Vue.js 3 + Vite + Element Plus + SVG图标 |
| 后端 | Spring Boot 4.1.x + MQTT Broker (EMQX) + MyBatis Plus |
| 数据库 | MySQL 8.x |
| 消息中间件 | MQTT over TCP (EMQX作为Broker) |
| 缓存 | Redis (会话/设备在线状态) |
| 部署 | Docker Compose |

### 1.3 UI/UX设计规范
- 极简主义、方正风格；主色为 ThingsCloud 蓝（`--color-primary: #165DFF`），中性色承载背景与文字（`--color-bg` / `--color-text-*`）
- 所有图标为SVG矢量格式
- 禁用Emoji和表情符号
- 功能色仅限：关键状态文字、特殊交互元素（成功/警告/危险/主要按钮）
- 响应式布局，四档断点（≥1440 / 1024–1440 / 768–1024 / <768），支持桌面、平板与手机
- 控件统一 Element Plus，色值/间距一律走 CSS 令牌，禁止硬编码

**站点分区与骨架（T-13）**

- 站点分区：公开站官网 `/`、文档站 `/docs`、认证 `/login`·`/register`；工作台 `/workbench`（需登录），旧路径 301 重定向到新路径
- 工作台五区骨架：顶栏 + 左导航 + 内容区 + 右上下文栏 + 底部状态栏，由 `components/layout/WorkbenchLayout.vue` 统一提供，页面不得自绘侧栏/顶栏
- 响应式四档：≥1440px 全展开；1024–1440px 右栏默认收起（按钮唤出）；768–1024px 左导航转 64px 图标态、右栏转抽屉、顶栏隐藏搜索、状态栏精简；<768px 左导航与右栏均转抽屉、顶栏仅 logo + 用户、状态栏仅通道状态
- 内容容器统一 `.page`（工作台 1440px 上限、居中）；官网/文档用 `.site-container`（1200px 上限）；文档正文用 `.page--narrow`（960px）

### 3.4 T-12 交付范围与未做项（R3 阶段，进行中）

**已交付（R3-1 认证元数据缓存与主动失效）**

- 主动失效：密钥重置（`DeviceCredentialResetServiceImpl.resetAndEvict`，单台与批量导出同一出口）、设备删除（`DeviceServiceImpl.deleteDevice`）、产品删除与标识改名（`ProductServiceImpl.delete` / `update`）后立即删缓存；失效失败退回 TTL 兜底

## 5. 可维护性与扩展性规范

### 5.1 代码规范
- 后端遵循阿里巴巴Java编码规范
- 前端遵循Vue.js官方风格指南
- 所有接口需写注释（Swagger/OpenAPI）
- 所有SQL需走MyBatis Mapper，禁止硬编码SQL

### 5.2 扩展规范
- 新增设备类型时创建对应**产品**（设备类型模板）即可，无需改动核心代码；设备归属于产品，`deviceKey` 在产品内唯一
- 新增MQTT Topic时在配置中心注册、无需修改核心代码；主题级授权规则集中在 `AclEvaluator`
- 新增前端页面时在router中注册、遵循Layout规范
- 接入第三方系统时通过Webhook或MQTT适配层集成

### 5.3 监控与维护
- 后端日志采用SLF4J + Logback、分级输出
- 关键指标通过 Spring Boot Actuator 暴露：`/actuator/health`、`/actuator/prometheus` 公开，`/actuator/info`、`/actuator/metrics` 仅 ADMIN（见 `SecurityConfig`）；Prometheus 指标由 `micrometer-registry-prometheus` 提供
- 设备接入的认证与授权由 EMQX HTTP 回调后端裁决，配置由 `scripts/emqx-init.sh` 幂等下发（compose 中的 `emqx-init` 服务），变更后需重建该服务
- 数据库需定期归档历史消息、设置分区表
- EMQX需配置集群模式、启用WebHook
