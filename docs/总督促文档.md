## 1. 项目总览

### 1.1 项目背景
构建一个完整的MQTT云平台系统，支持MQTT核心通信、用户认证、设备管理、实时消息监控及历史数据查询。

### 1.2 技术栈
| 层级 | 技术选型 |
|------|----------|
| 前端 | Vue.js 3 + Vite + Element Plus + SVG图标 |
| 后端 | Spring Boot 3.x + MQTT Broker (EMQX) + MyBatis Plus |
| 数据库 | MySQL 8.x |
| 消息中间件 | MQTT over TCP (EMQX作为Broker) |
| 缓存 | Redis (会话/设备在线状态) |
| 部署 | Docker Compose |

### 1.3 UI/UX设计规范
- 极简主义风格，黑白灰色系（#FFFFFF, #F5F5F5, #333333）
- 所有图标为SVG矢量格式
- 禁用Emoji和表情符号
- 点缀色仅限：关键状态文字、特殊交互元素（成功/警告/危险/主要按钮）
- 响应式布局，支持桌面及平板设备

## 5. 可维护性与扩展性规范

### 5.1 代码规范
- 后端遵循阿里巴巴Java编码规范
- 前端遵循Vue.js官方风格指南
- 所有接口需写注释（Swagger/OpenAPI）
- 所有SQL需走MyBatis Mapper，禁止硬编码SQL

### 5.2 扩展规范
- 新增设备类型时仅需扩展Device表类型字段及对应Service
- 新增MQTT Topic时在配置中心注册、无需修改核心代码
- 新增前端页面时在router中注册、遵循Layout规范
- 接入第三方系统时通过Webhook或MQTT适配层集成

### 5.3 监控与维护
- 后端日志采用SLF4J + Logback、分级输出
- 关键指标（设备在线数、消息吞吐量）需暴露/actuator接口
- 数据库需定期归档历史消息、设置分区表
- EMQX需配置集群模式、启用WebHook
