## Global Constraints

- 每个阶段结束必须通过：`npm run test` && `npm run build` && `npm run lint`，否则不得进入下一阶段。
- 阶段内提交按主题拆分（如「F1 骨架组件」「F2 路由分区」），不混合提交。
- 任何新文件不得硬编码色值/字体，必须引用 `variables.css` 令牌。
- 任何页面不得自绘顶栏/侧栏/页脚，骨架统一由 `layout/*` 提供。
- 任何页面根容器统一使用 `.page`，不得再出现页面级 `max-width` 特例（文档正文除外，用 `.page--narrow`）。
- 不使用 Emoji 作为图标；图标统一走 `components/common/Icon.vue`。
- 表单控件统一 Element Plus；不新增原生 `<select>`/`<input>`（文件上传、日期等由 `el-*` 覆盖）。
- 旧路由必须保留 `redirect`，不得出现 404。
- 迁移期间保留一次性令牌别名，收尾阶段（F6）统一删除。

|------|----------|------|

### 关键风险

| 风险 | 触发信号 | 处置 |
|------|----------|------|
| 迁移漏引用导致白屏 | `build` 失败或运行时报模块找不到 | 按阶段提交，逐阶段回滚定位 |
| 令牌别名长期残留 | F6 未清理 | F6 强制任务，检索确认 |
| SSE 上提后消息页异常 | 消息页无数据或重复渲染 | 保留 store 事件缓冲；必要时临时双通道过渡 |
| Element Plus chunk 膨胀 | 构建产物体积上升 | 核对按需解析器生效，避免整包 barrel |
| 官网/工作台宽度混淆 | 内容居中异常 | 明确 `--site-max-width`(1200) 与 `--content-max-width`(1440) 使用边界 |
