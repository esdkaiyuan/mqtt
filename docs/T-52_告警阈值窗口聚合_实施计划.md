# T-52 告警阈值窗口聚合 实施计划

> 版本：v1.0　创建日期：2026-10-22　状态：已交付
> 目标：补齐 G-7-2，让阈值告警支持「最近 N 秒的 AVG / MIN / MAX / SUM / COUNT 越限」，而不只看最新一条属性值。

---

## 1. 背景与范围

当前阈值告警由 `AlertEvaluationServiceImpl` 对每条上报的最新值即时比较，无法表达「5 分钟均值越限」这类工业场景常见规则。本任务：

- `THRESHOLD` 规则增加可选窗口：`windowSeconds`、`aggregateType`、`minSamples`；
- 窗口为 0 时保持现有「最新值」语义，存量规则行为逐位不变；
- 窗口聚合在评估侧维护，样本计入本副本内存窗口，按上报时间滚动淘汰；
- 支持 `AVG` / `MIN` / `MAX` / `SUM` / `COUNT`；
- 达到 `minSamples` 后才参与比较；不足样本时既不触发也不恢复活动告警；
- 告警触发值保存聚合值（而非最新样本），标题展示窗口与聚合方式；
- 前端规则表单支持窗口配置，列表展示窗口摘要。

不在本任务范围：跨副本共享窗口、窗口持久化 / 重启恢复、事件与离线规则的窗口、复杂表达式（滑动中位数 / 分位数）、窗口内多标识符联合聚合。

---

## 2. 数据模型

### 2.1 迁移 `V30__alert_window.sql`

`alert_rule` 增加：

| 列 | 默认 | 说明 |
|---|---|---|
| `aggregate_type` | `NULL` | `AVG` / `MIN` / `MAX` / `SUM` / `COUNT`；窗口为 0 时为空 |
| `window_seconds` | 0 | 1~86400；0 表示实时最新值 |
| `min_samples` | 1 | 1~1000；窗口内达到该样本数才评估 |

只加列、不改既有列；存量规则 `window_seconds=0`，行为不变。

### 2.2 聚合口径

- 只接受可解析为十进制数的属性值；非数值样本不入窗；
- `AVG` 保留足够精度并去掉尾零；`MIN` / `MAX` / `SUM` 使用 `BigDecimal`；
- `COUNT` 返回窗口内数值样本数；
- 窗口按 **上报时间** 计算，`[anchor - windowSeconds, anchor]`，`anchor` 取已见最大上报时间，避免乱序样本把窗口反向拉长；
- 单规则单设备窗口最多保留 10,000 个样本；内存窗口最多 10,000 个 key，超出时清空并记 WARN（P2 保护，正常规模不会触发）。

## 3. 后端实现

- `AlertConstants`：聚合方式常量与集合；
- `AlertRule` / `AlertRuleRequest` 增加 `aggregateType` / `windowSeconds` / `minSamples`；
- `AlertRuleServiceImpl` 校验并规范化：
  - 仅 `THRESHOLD` 允许窗口；窗口 >0 时聚合方式缺省 `AVG`，阈值必须是数字；
  - 窗口 0 时清空聚合方式、`minSamples=1`；非阈值来源强制窗口 0；
  - 规则更新 / 删除时清理对应内存窗口；
- 新增 `AlertWindowAggregator`：按 `(ruleId, deviceId)` 维护滚动窗口，返回 `Optional<Aggregate>`（聚合值与样本数）；
- `AlertEvaluationServiceImpl`：
  - 窗口规则调用聚合器；不足样本直接返回；
  - 命中触发 / 未命中恢复沿用现有 `raise` / `recover`；
  - 触发值写聚合值，标题包含「N 秒 AVG」等说明；
- 无新增接口；规则列表 / 详情直接返回新字段。

## 7. 关键决策与已知限制

1. **窗口为 0 完全保持旧语义**：存量规则不受影响，避免一次升级改变所有告警行为。
2. **内存窗口而非历史表查询**：告警评估与属性历史写入同一解析链路，历史表在评估之后才落库，查历史会漏掉当前批；内存窗口无额外 DB 查询，代价是重启 / 副本切换后窗口清空。
3. **按上报时间而非处理时间**：乱序上报不会把窗口拉长；`anchor` 取最大已见时间。
4. **不足最少样本不恢复**：窗口刚建立或数据稀疏时，不应把已触发告警误判为恢复。
5. **单副本窗口**：设备上行按共享订阅路由到单副本，正常链路可用；多副本重平衡会丢窗口，需后续用 Redis / 流处理补齐。
6. **仅阈值规则**：事件 / 离线告警没有连续数值序列，窗口语义不成立。
